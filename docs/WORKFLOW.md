# Fluxo de atualização

Este repositório é a fonte principal do código da loja Sabryna Dahur.

## Atualizar o projeto local

Na pasta do projeto, execute:

```bash
git pull origin main
```

## Enviar alterações feitas localmente

```bash
git add .
git commit -m "descrição da alteração"
git push origin main
```

Não versionar arquivos `.env`, credenciais, tokens, `node_modules` ou dados privados de clientes.

> Observação: alterações feitas diretamente no GitHub devem ser sincronizadas no computador com `git pull origin main` antes de continuar o desenvolvimento local.
